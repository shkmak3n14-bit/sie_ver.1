# /src/core

## 責務

診断エンジン（ロジック層）。サイの「頭脳」。
135問診断・スコアリング・タイプ判定・補正を担当する。

## サブモジュール

| フォルダ | 責務 |
|---------|------|
| `questions/` | 質問データ（YAML） |
| `scoring/` | スコアリング・重み付け |
| `type_engine/` | 総合評価・最終タイプ決定 |
| `center_engine/` | センター補正（先決定しない） |
| `wing_engine/` | w 補正（タイプ確定後） |
| `episode_analysis/` | エピソード解析・補正 |

## 独立性

- **`src/dialogue/` への依存禁止**
- 人格・口調・セリフは一切含まない
- 出力は構造化データ（タイプ・スコア・確信度）のみ

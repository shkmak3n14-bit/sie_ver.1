# /src/dialogue/flow

## 責務

診断前導入、質問の出し方、回答後フィードバック、自己理解・他者理解・相互理解フェーズの対話フロー。

## ファイル

| ファイル | 内容 |
|---------|------|
| `intro.yaml` | 診断前の導入 |
| `questioning.yaml` | 質問の出し方 |
| `feedback.yaml` | 回答後フィードバック |
| `self_understanding.yaml` | 自己理解フェーズ |
| `other_understanding.yaml` | 他者理解フェーズ |
| `relationship.yaml` | 相互理解フェーズ |

## 依存

- **参照可**: `persona/`, `templates/`, `src/models/`
- **参照禁止**: `src/core/`
